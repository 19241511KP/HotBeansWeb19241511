Apprentice Frontend
Software Engineer
(Level 4)

Description: An apprentice frontend developer builds user interfaces using HTML, CSS, JavaScript, and frameworks like React, ensuring cross-browser compatibility, accessibility, and valid code. They shadow teams, write and test simple web pages, and follow web standards while developing under supervision.

Salary range: £14.000-£21.000
