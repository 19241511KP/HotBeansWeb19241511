Our web development courses

Foundations of Web Design (HTML & CSS)

In this course students will learn how to structure web pages using HTML and style them using CSS. By the end of this course you will be able to create responsive, visually attracting websites and understand core layout techniques.

Target audience:

Beginners with no programming experience who are interested in out front-end development apprenticeship

Entry Skills:

  • Basic computer literacy
  • No programming experience required

Cost: £450

JavaScript Essentials

This course focuses on programming fundamentals using JavaScript. Students will understand variables, functions, loops, and events, and how to use JavaScript to create dynamic and interactive web applications. It also introduces basic debugging and problem-solving techniques.

Target audience:

Beginners with basic HTML and CSS knowledge

Entry Skills:

  • CSS & HTML knowledge
  • No programming experience required

Cost: £500

Pythond Fundamentals

This course introduces programming concepts using Python, focusing on backend development skills. Learners will cover data types, control flow, functions, file handling, and basic web frameworks. The course also introduces how backend systems interact with databases and APIs.

Target audience:

Beginners without prior backend development experience who are interested in our backend development apprenticeship

Entry Skills:

  • Basic computer literacy
  • Basic knowledge of HTML, CSS & JavaScript preferred but not required

Cost: £550

Introduction to Kotlin

This course provides an introduction to mobile development using Kotlin. Students will explore programming fundamentals, Android app structure, user interfaces, and simple app deployment. By the end, students will build a basic mobile application.

Target audience:

Beginners aiming to enter mobile development apprenticeships without prior experience in Java, Kotlin, or Swift.

Entry Skills:

  • Basic computer literacy
  • No programming experience required

Cost: £550
